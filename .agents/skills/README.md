# Project Skills

This registry lists the project Skills under .agents/skills/. The verifier discovers Skill directories from the filesystem and requires every Skill to appear here exactly once.

- [project-plan](project-plan/SKILL.md) — Plan substantive changes with scope, ownership, architecture, risks, tests and acceptance criteria.
- [project-implement](project-implement/SKILL.md) — Implement an agreed change with focused diffs, regression coverage, documentation and reproducible verification.
- [project-review](project-review/SKILL.md) — Independently review correctness, architecture, security, compatibility, tests, documentation and operational risk.
- [project-pre-pr](project-pre-pr/SKILL.md) — Verify scope, quality evidence, defensive patterns, documentation and release boundaries before opening or updating a PR.
- [project-doc-writing](project-doc-writing/SKILL.md) — Create or revise documentation while preserving ownership, links, contracts and verification evidence.
- [project-error-handling](project-error-handling/SKILL.md) — Design or review exceptions, retries, cancellation, timeouts, cleanup and failure reporting.
- [project-simplification](project-simplification/SKILL.md) — Identify evidence-backed reductions without losing required behavior or moving complexity elsewhere.
- [project-upgrade-guide](project-upgrade-guide/SKILL.md) — Write migration guidance for externally observable API, CLI, configuration, schema or operational changes.
- [project-agent-governance](project-agent-governance/SKILL.md) — Audit AGENTS.md hierarchy, compatibility entry points and Skill registry metadata.
