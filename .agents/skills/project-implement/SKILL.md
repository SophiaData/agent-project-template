# Project implementation

1. Read `AGENTS.md`, the agreed plan and code in scope.
2. Use a topic branch/worktree, protect unrelated work and avoid new dependencies without a rationale.
3. Add tests for behavior, errors and regression; update contracts/docs if needed.
4. Run real configured checks; disclose missing tools or failures, never forge outputs.
5. Summarize changed files, exact checks, remaining risks and independent review request.
6. Do not auto-merge or deploy.
